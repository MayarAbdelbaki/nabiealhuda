# Msegat SMS OTP & WhatsApp

Odoo 19 integration with [Msegat](https://web.msegat.com/):

- **Phone verification of new customers**: external users (website sign-up, portal invitation)
  confirm their phone number once with a code sent by Msegat, at their first login. Later logins only
  need the password. Internal users are not concerned.
- **Invoices by WhatsApp**: a *Send by WhatsApp* button on posted customer invoices and credit notes
  (also in the list view *Actions* menu) sends the invoice PDF to the customer's phone.

APIs used:

- SMS and OTP: Msegat gateway `https://www.msegat.com/gw/`
  ([documentation](https://documenter.getpostman.com/view/39158411/2sBY4LT3EY)).
- WhatsApp: Msegat's WhatsApp Business service runs on T2 Communicate,
  `https://communicateapi.t2.sa/api` (`/auth/login`, `/message/send-custom`).

## Setup

Everything is in **Settings > Msegat**, per company.

### Msegat account

1. Enter the **username**, the **API key** (msegat.com > Settings > API) and an activated **sender name**.
2. Click **Check Balance** to test the credentials.

To test verification codes for free before your sender name is activated, use the sender `auth-mseg` with the
method *Code generated by Odoo, sent as an SMS* and keep the message `Pin Code is: {code}`.

### Phone verification

1. Enable **Verify the Phone of New External Users**.
2. Choose the method:
   - *Msegat OTP service*: Msegat generates, sends and checks the code (`sendOTPCode.php` /
     `verifyOTPCode.php`), in Arabic or English.
   - *Code generated by Odoo, sent as an SMS*: Odoo generates the code and sends your message text
     through `sendsms.php`.

From then on, each new external user account is flagged *Phone Verification Pending*. After a
website sign-up, the customer goes straight to the verification page: they enter their mobile number
(or confirm the one on their contact), receive the code and type it. The account cannot be used until
then; once verified, the number is saved on their contact and the flag is removed, so later logins
only ask for the password.

Accounts that existed before are not asked. To ask a given user, tick **Phone Verification Pending**
in the *Security* tab of their user form.

Numbers are converted to the international format Msegat expects (`9665XXXXXXXX`), using the
contact's country, else the company's. Limits: 4-digit code, valid 5 minutes, 3 attempts per code,
5 codes per user per hour. Sent codes are listed under **Verification Codes** (kept 30 days).

### WhatsApp invoices

1. Activate WhatsApp in your Msegat account and enter the **email and password** of the WhatsApp
   (T2 Communicate) account. Click **Test Connection**.
2. WhatsApp only lets a business start a conversation with a template approved by Meta. Create a
   template with a **Document** header, for example (Utility category):

   > Dear {{1}}, please find attached invoice {{2}} of {{3}}. Thank you.

   Enter its name as **Msegat WhatsApp Template**, and the values of its variables, in order, as
   **Template Variables**: `partner_name,invoice_number,amount_total`. Available values:
   `partner_name`, `invoice_number`, `amount_total`, `amount_residual`, `invoice_date`,
   `invoice_date_due`, `company_name`.
3. The other mode, *PDF message*, sends the PDF without a template; WhatsApp only delivers it if the
   customer wrote to you in the last 24 hours.

WhatsApp downloads the PDF from Odoo, so **`web.base.url` must be the public address of this Odoo**
(not `localhost`). The link is signed and expires after a few weeks. The PDF sent is the one generated
by *Send* when it exists, otherwise a new rendering of the invoice report.
